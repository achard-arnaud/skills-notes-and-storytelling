# Buy-side gap analysis candidate fixture

Decision: assess whether a challenger can replace, coexist with or complement an incumbent automation platform.

Regression checks:
- buyer baseline and desired state precede feature comparison;
- at least one hard gate is evaluated before scoring;
- comparison is a table and migration includes rollback;
- buyer gaps remain separate from seller recommendations;
- lock-in is mapped to concrete stack/value-chain control points with portability/exit path;
- recommendation includes a reversible validation step;
- complementarity/coexistence can bridge to `integration-note` with technical/product/business questions preserved;
- bridge carries prior evidence and rejected alternatives rather than restarting research;
- mandatory dreaming check runs after delivery.
