# Hivest Portfolio AI

Dans le dépôt `Hivest-ptf-analysis`, lire [AGENTS.md](../../AGENTS.md), `program/state.json` et le manifest de **l'entité concernée**. Si le dépôt est distant, récupérer ces fichiers ciblés. Le dépôt est l'autorité sur les contrats, versions et états ; cette skill en est l'export de procédure.

Lire [references/workflow.md](references/workflow.md) pour choisir l'étape, son contrat entrée/sortie et **la procédure suivante**. Charger une seule référence métier à la fois : `evidence` → `market-drivers` → `diagnostic` → `opportunities` → `review` → `composition` → `learning`. Revenir à `evidence` pour une question ciblée ou un gate de preuve ouvert. `research-graph` accompagne uniquement reprise/recherche/intégration ; `exec-writing` accompagne uniquement `composition` en profil exec. Les chemins exacts et les conditions sont dans le workflow.

Appliquer [les gates](../../docs/agent/gates.md) et [le protocole de reprise](../../docs/agent/context-and-resume.md) seulement quand leur sujet est actif. Une étape ne peut passer la main sans ses sorties contrôlées ; noter le checkpoint dans l'index/manifest. Ne jamais traiter une fixture, une synthèse ou un rendu comme preuve d'un gate fermé.
