# Select a narrative schema

1. Read the [schema reference](references/narrative-schemas.md). Identify the requested decision or learning task. Preserve the chosen domain and delivery format as separate inputs.
2. Gather only the selected claim IDs, statuses, source locators, limitations and relevant relations. If the decision or its proof is unresolved, return the specific question to its owner.
3. For a direct note, run the selector against the scoped packet. For a case, use the A2 call with the A1 ledger. Bind the sections to claims and keep side stories as candidates.
4. For A3, read the current section packet. For A4 or a short-note review, check the decision, strongest counterevidence and traces. Return findings with an owner, action and exit test. The human records editorial approval.
