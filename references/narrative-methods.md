# Narrative method registry

Choose one primary method; supporting practices must serve a reader decision.

| ID | Logic | Use | Gate |
|---|---|---|---|
| pyramid | answer → reasons → evidence | executive decision | child claims support conclusion |
| issue-tree | question → testable branches | uncertain diagnosis | evidence or gap per branch |
| comparison | same criteria → alternatives → judgment | benchmark | same unit/scope |
| mechanism | conditions → mechanism → outcome → limits | technical/economic | no causality from correlation |
| learning | familiar problem → example → explanation → practice | training | define terms first |

Pyramid Principle is associated with Barbara Minto; do not attribute all these practices to McKinsey.
Action titles state insights rather than topics. MECE checks material gaps and overlaps without forcing
false independence. Ghost deck means validate claim sequence before design, including prose notes.
Signal-to-noise removes material that neither proves a point nor explains a necessary limitation.
Scaffold: section ID, reader question, action title, claim IDs, transition, payload. Internal consistency
review suffices unless the user requested approval. Side stories remain secondary, never a rival thesis.
