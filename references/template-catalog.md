# Template catalog

| Enum | Primary decision | Orientation | Default length | Lifecycle |
|---|---|---:|---:|---|
| ARCHITECTURE_NOTE | understand architecture, scale, risks, economics | portrait | 5–10 pp | validated |
| ONE_PAGER | fast executive orientation | adaptive | 1 p | validated |
| TWO_PAGER | compact due diligence / company-product-person | landscape | 2 pp | validated |
| BENCHMARKING | compare multiple options consistently | landscape | 2–6 pp | candidate |
| BUY_SIDE_GAP_ANALYSIS | adopt / replace / complement / partner | adaptive | 4–8 pp | candidate |
| DIAGNOSTIC_RECO_SELL_SIDE | improve seller positioning and commercial model | portrait | 5–9 pp | validated |
| OPPORTUNITY_NOTE_ICP | decide whether one target/partner is a credible opportunity | portrait | 4–8 pp | validated |
| ACTION_PLAN | turn an accepted analysis into sequenced execution | adaptive | 2–8 pp | TODO |

All production templates are analysis-first. `ACTION_PLAN` is a downstream derivative and remains non-production.

## Diagnostic-reco-sellside
Required:
- seller truth;
- market/competitive pressure;
- seven-dimensional ICP + anti-ICP;
- hard gates;
- entry wedge;
- proof/acceptance;
- packaging/pricing;
- commercial options;
- recommendations;
- validation questions.

No 30/60/90 roadmap inside this template.

## Opportunity-note-ICP
Required:
- target truth;
- product truth;
- seven-dimensional ICP + anti-ICP;
- hard gates;
- scenario/use-case canvas when partnership-oriented;
- gap → capability → outcome;
- alternatives;
- stakeholder lanes;
- validation option;
- win-win / option value;
- decision and discussion questions.
