# Evidence, scaffold and retrieval

## Records
Fragments hold atomic source material, stable ID, source ID, locator, status, entity and date.
Claims hold propositions and fragment IDs; sections order claim IDs by narrative purpose.
Side stories reference claims and section anchors. Version each separately; reordering is not new proof.
Business edges: supports, contradicts, qualifies, causes, depends_on, compares_to, answers, motivates.
Causality requires a mechanism. Nodes cover fragment, claim, decision, recommendation and unknown;
entity/tags distinguish economics, capabilities, organization, timing, risk and market without imposing
historical causal arcs. User directions are requirements, never factual evidence.

## Intake and collection
Inventory source families, origin, pages/sections and reading coverage. Distinguish physical PDF page,
printed page and article number. Extract once; segment by coherent section/paragraph, retain adjacent
caveats. Deduplicate headers for retrieval while preserving locators. Extraction is not reading.
Record every manual section as read/excluded/unread with reason; every requested topic gets a disposition.
Read original context before promoting retrieved material. A supplied vendor document remains attributed.

Gap records carry ID, target claims, reason (missing/contradiction/freshness/independence), query,
searched families and disposition. Consume manual inputs before gap searches. Snippets are leads;
read primary pages. Repeated vendor/partner publications are not independent confirmation.
Stop when direct evidence closes a gap, repeated searches add nothing, or budget is used. Preserve unknowns.

## Retrieval and ranking
Retrieve by exact ID/entity/section first, then lexical overlap for query candidates. Hydrate target
claims, their fragments and transitive dependencies; include contradictions/qualifications in both
directions. Avoid traversing every comparison edge. Apply gates before scores: relevance .30,
strength .25, explanatory value .20, novelty .15, audience .10. Ties use stable IDs. Scores do not
prove claims. Required targets/counterevidence survive top-k and budgets; overflow triggers staged reading.
The bundled implementation is lexical retrieval plus weighted ranking, not embeddings or a learned
semantic reranker. Model semantic review remains necessary before scaffold approval.

## Iteration and composition
Changed fragments affect citing claims, dependent claims, sections and side stories. Return affected
and preserved IDs. Reassess freshness/status and append reason/parent baseline. Keep unrelated accepted
prose byte-stable when possible. From scratch excludes old generated prose. Global topology stays compact;
section-local packets supply material. Reconcile requested claim coverage after drafting.

Side stories: dezoom/method/false_lead/comparator/analytical_focus/callback. Essential analysis stays in
core sections. Narrative stories require insertion and return section IDs. Method apparatus may have
null return and be self-contained. Store included/deferred/rejected disposition with reason. Never invent
an anchor or promote evidence through a story. Sharing fragments across stories is not corroboration.
