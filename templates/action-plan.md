# Template — Action plan

Version: 0.1.0
Lifecycle: TODO / non-production

## Purpose
Turn an accepted upstream analysis into sequenced implementation.

## Required upstream input
- source artifact type;
- source artifact version;
- accepted decision/recommendation;
- explicit user request for execution planning.

## Planned payload
- objectives;
- workstreams;
- owners;
- dependencies;
- milestones/cadence;
- optional 30/60/90 structure;
- metrics;
- risks;
- escalation/stop gates.

## Boundary
This template must never be invoked implicitly by an analytical template.
