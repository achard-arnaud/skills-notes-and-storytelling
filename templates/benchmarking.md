# Template — Benchmarking

Use for 2+ options assessed against identical criteria.

Required:
- decision criterion;
- common baseline;
- hard gates before scores;
- comparison matrix;
- sensitivity / uncertainty;
- recommendation;
- falsifiers.

Default comparison presentation is a table with density-aware widths. Scores are heuristics unless an external validated scale exists.

## Couches (4-layer)

Ce template est un cas concret des [4 couches découplées](../references/layered-architecture.md). Voir la ligne `BENCHMARKING` de la table de déclinaison pour l'objectif/longueur, les frameworks narratifs par défaut, la typologie de nodes dominante et les règles de vocabulaire propres à ce template.
