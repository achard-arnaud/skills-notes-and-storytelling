# Template — Opportunity note ICP

Version: 1.1.0

## Purpose
Decide whether a target account, partner, product team or internal platform is a credible opportunity for one offer.

This is an **analysis and discussion template**. It clarifies scenarios, fit, risks and the next validation. It does not produce a 30/60/90-day implementation plan.

## Boundary
Build target reality independently from product truth. Cross them only after both sides are explicit.

Use `references/icp-and-fit-contract.md`.

## Decision spine
1. Opportunity decision and why-now.
2. Target reality: strategy, architecture, operating constraints, priorities.
3. Product truth: proven, plausible, planned, unknown.
4. ICP and anti-ICP across seven dimensions.
5. Hard gates `PASS | OPEN | FAIL`.
6. Opportunity scenarios / use cases.
7. Gap → capability → outcome mapping.
8. Alternatives: build / buy / partner / defer.
9. Stakeholder lanes.
10. Representative validation: demo, workshop, replay, benchmark or pilot hypothesis.
11. Win-win and longer-term option value.
12. Decision: `PURSUE | VALIDATE | NURTURE | DISQUALIFY`.
13. Questions for the next discussion.

## Seven-dimensional ICP
Describe:
- problem intensity;
- maturity/readiness;
- repeatable workflow/unit of value;
- technical prerequisites;
- organization and ownership;
- economics / measurable value;
- timing trigger.

Also define:
- anti-ICP;
- sponsor/promoter;
- prescriber/domain authority where relevant;
- terrain owner/users;
- technical sponsor;
- veto/control;
- evidence needed to upgrade confidence.

## Opportunity scenarios
When the target is a partnership or platform relationship, structure each scenario with the same simple canvas:

| Field | Requirement |
|---|---|
| Starting problem | Concrete target gap or desired outcome |
| Role of the offer | Capability supplied |
| Role of the target | Capability / asset supplied |
| Win for target | Business/product/delivery value |
| Win for offer | Proof, distribution, product learning or revenue option |
| Validation | Smallest credible demo/workshop/proof |
| Critical condition | What would invalidate the scenario |
| Longer-term option | Optional extension after proof |

Rank scenarios by:
- value;
- evidence;
- ease of validation;
- strategic option value.

## Side stories
- false_lead — feature similarity without outcome fit;
- comparator — nearest credible alternative;
- analytical_focus — integration/economic mechanism;
- dezoom — strategic option value;
- method — evidence and access limits.
