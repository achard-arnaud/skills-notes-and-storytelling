# Template — One-pager

One decision, one page.

Required:
- headline answer;
- 3–5 decisive facts;
- one diagram or one comparison table;
- recommendation;
- 1–3 next actions;
- compact sources.

No appendix inside the page.

## Couches (4-layer)

Ce template est un cas concret des [4 couches découplées](../references/layered-architecture.md). Voir la ligne `ONE_PAGER` de la table de déclinaison pour l'objectif/longueur, les frameworks narratifs par défaut, la typologie de nodes dominante et les règles de vocabulaire propres à ce template. Le registre des méthodes narratives est détaillé dans [references/narrative-frameworks.md](../references/narrative-frameworks.md) ; les règles de retrieval/reranking claims vs fragments dans [references/retrieval-and-reranking.md](../references/retrieval-and-reranking.md).
